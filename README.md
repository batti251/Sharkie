# 🦈 Sharkie – Swim ’n’ Run Game

Sharkie is a browser-based Swim ’n’ Run game built with vanilla JavaScript, focusing on Object-Oriented Programming and performance optimization.

## Overview
Sharkie is a Jump ’n’ Run–style game developed as part of the Developer Akademie Frontend Course.  
The project focuses on applying Object-Oriented Programming principles in JavaScript while maintaining good performance in a browser environment.

---

## Learning Goals
- Apply Object-Oriented Programming (OOP) concepts in JavaScript
- Structure a larger JavaScript codebase using classes and inheritance
- Handle game logic, collisions, and animations
- Optimize performance in a browser-based game

---

## Tech Stack
- **HTML5** – Canvas rendering and structure  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – Game logic, OOP, animations
- No external libraries

---

## Features

### Controls
- Move Sharkie using **Arrow keys** or **WASD**
- **SPACE** – Melee attack (Fin Slap)
- **Q** – Shoot a bubble (requires poison flask)

### Controls - mobile
- Play the game on your mobile Device, ain't no matter the size!

### Collectibles
- **Poison Flasks** – Enable bubble attacks
- **Coins** – Currently cosmetic (future functionality planned)

### Enemies
- Jellyfish
- Pufferfish
- Endboss

### Combat
- Avoid enemies or attack them
- Melee attacks work on all enemies
- Bubble attacks only affect Jellyfish and the Endboss

### Music
- Background Music
- Several Sound effects
- Adjust the Volume by a control unit
